# Baking Timer - 화면 와이어프레임

**버전**: 0.1.2
**최종 수정일**: 2026-05-05

이 문서는 현재 구현된 화면의 구조와 컴포넌트, 화면 간 이동 흐름을 정의합니다.

---

## 1. 진입 흐름

```
앱 실행
  ↓
[스플래시 화면] - 로고 페이드인 + 아이콘 회전 애니메이션
  ↓ (자동)
[시작 화면 (LoginScreen)] - 앱 타이틀 및 시작하기 버튼
  ↓
[메인 화면 (MainScreen)] - 하단 탭 네비게이션
```

---

## 2. 메인 프레임 (Main Frame)

하단 네비게이션 바 5개 탭:

| 탭 인덱스 | 아이콘 | 화면 |
|-----------|--------|------|
| 0 | receipt_long | 내 레시피 |
| 1 | menu_book | 가이드 |
| 2 | calculate | 계산기 |
| 3 | timer | 타이머 |
| 4 | settings | 설정 |

---

## 4. 화면 이동 흐름

```
SplashScreen
  └→ LoginScreen (시작 화면)
       └→ MainScreen
            ├─ [탭 0] MyRecipesScreen
            │    └→ RecipeDetailScreen
            │         └→ TimerSetupScreen
            │              └→ MainScreen (탭 3 자동 전환)
            ├─ [탭 1] GuideScreen
            ├─ [탭 2] CalculatorTabScreen
            │    ├─ CalculatorScreen
            │    └─ DoughCalculatorScreen
            ├─ [탭 3] TimerScreen
            └─ [탭 4] SettingsScreen
                  └→ LoginScreen (앱 정보 탭 시)
```
