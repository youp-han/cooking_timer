## Baking Timer: 제품 요구사항 명세서 (PRD)

**버전**: 0.1.2
**최종 수정일**: 2026-05-05

### 1. 문서 개요

본 문서는 'Baking Timer' 애플리케이션의 기능, 사용자 경험(UX), 시스템 요구사항을 정의합니다.

*   **프로젝트 목표:** 사워도우 베이킹 과정의 복잡한 계산을 자동화하고, 다단계 타이머로 베이킹 과정을 관리하여 모든 수준의 베이커가 더 즐겁고 성공적인 베이킹을 할 수 있도록 돕는다.

### 2. 사용자 분석 (User Personas)

*   **초보 베이커:** 사워도우 베이킹을 이제 막 시작하여 레시피의 '피딩 비율'이나 '베이커스 퍼센트' 같은 개념이 낯선 사용자. 정확한 계산과 상세한 가이드가 필요하다.
*   **중급 베이커:** 기본적인 베이킹은 가능하지만, 다양한 레시피를 시도하며 결과물의 일관성을 높이고자 하는 사용자. 레시피에 따른 정확한 재료 계산 기능이 중요하다.
*   **숙련 베이커:** 자신만의 레시피를 개발하고 베이킹 과정을 최적화하려는 사용자. 다양한 비율을 실험하고 결과를 예측하는 데 계산기를 유용하게 사용한다.

### 3. 핵심 기능 명세

#### 3.1. 베이커스 계산기 (Sourdough Calculator)

*   **설명:** 총 르방(스타터) 양을 기준으로 스타터, 밀가루, 물의 양을 계산하는 기능입니다.
*   **요구사항:**
    1.  **입력:** 총 르방 양(g), 온도(°C), 준비 시간 (4-24시간 범위 선택)
    2.  **준비 시간 기반 자동 비율 적용:** 시간 범위에 따라 피딩 비율(스타터:밀가루:물) 자동 설정
    3.  **수동 비율 조정:** 자동 적용된 비율을 사용자가 직접 수정 가능
    4.  **결과 표시:** 스타터, 밀가루, 물의 최종 양(g) 실시간 표시
    5.  **레시피 저장:** 계산 결과를 레시피로 저장 (calculationType: 'unified')

#### 3.2. 도우 계산기 (Dough Calculator)

*   **설명:** 베이커스 퍼센티지 기반으로 도우 재료를 계산하는 기능입니다.
*   **요구사항:**
    1.  **두 가지 모드:** 총 도우 기준 / 재료 기준 토글 전환
    2.  **양방향 입력:** % 입력 시 g 자동 계산, g 입력 시 % 역계산 및 전체 재료 재조정
    3.  **밀가루 상세 입력:** 강력분, 통밀, 호밀 등 여러 종류 혼합 가능
    4.  **추가 재료:** 올리브유, 버터 등 추가 재료 입력 지원
    5.  **레시피 저장:** 계산 결과를 레시피로 저장 (calculationType: 'dough')

#### 3.3. 내 레시피 관리

*   **요구사항:**
    1.  저장된 레시피 목록 표시 (최신순)
    2.  레시피 상세 보기 (재료 및 계산 결과)
    3.  레시피 삭제
    4.  레시피에서 타이머 시작

#### 3.4. 타이머 시스템

*   **요구사항:**
    1.  레시피 타입별 기본 템플릿 자동 로드 (사워도우 16h / 일반 도우 4h)
    2.  단계 추가/수정/삭제
    3.  백그라운드에서 타이머 실행 (앱 종료 후에도 동작)
    4.  1초 단위 카운트다운 표시
    5.  단계 전환 시 알림 발송
    6.  완료 시 초록색 완료 화면 표시 후 자동 삭제

#### 3.5. 가이드

*   **요구사항:**
    1.  베이커스 계산기, 도우 계산기, 타이머 사용법 안내
    2.  베이커스 퍼센티지 개념 및 계산 예시
    3.  제빵 용어 설명

#### 3.6. 설정

*   **요구사항:**
    1.  타이머 알림 켜기/끄기 토글
    2.  문의 및 버그 리포트 이메일 전송
    3.  앱 버전 정보 표시

### 4. 화면 구조

*   **전체 구조:** 하단 탭 네비게이션 5개 탭
    - 탭 0: 내 레시피
    - 탭 1: 가이드
    - 탭 2: 계산기 (베이커스 / 도우 탭 내부 전환)
    - 탭 3: 타이머
    - 탭 4: 설정

*   **진입 흐름:** 스플래시 화면 → 시작(타이틀) 화면 → 메인
